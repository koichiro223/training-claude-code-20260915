# 要求内容 — バルーン肥大化演出（カウントダウン中に大きくなる）

## 0. この作業バッチの位置づけ

- 作業バッチ名：`20260915-balloon-grow`
- 対象：バルーン遊び画面（`/play`）の演出強化。カウントダウンが進むあいだ、表示中のバルーンが少しずつ大きくなるようにする。
- 依存：**`20260915-balloon-game` 完了が前提**（`useBalloonGame` / `Balloon` / `BalloonStage` が既存）。
- 影響範囲：`components/balloon/` と `@/lib/constants` のみ。logs/schedules 状態・Context・永続化には一切影響しない。

## 1. 変更・追加する機能の説明

バルーン遊びで、バルーンが「時間のカウントダウンをしている間、大きくなる」演出を追加する。

- 発生直後は現状どおり見やすいサイズ（初期直径）で出現する。
- カウントダウンが進む（残り時間が減る）ほど、バルーンの表示サイズが滑らかに拡大する。
- 破裂（タップ／自動）で次のバルーンが生成されると、サイズは再び初期サイズから始まる。
- 「膨らんでいくバルーン」という視覚的な楽しさ・緊張感を与え、破裂への期待を高める。

## 2. ユーザーストーリー

- 赤ちゃんとして、バルーンがだんだん大きく膨らんでいくのを見て、はじける瞬間を楽しみに待ちたい。
- 保護者として、バルーンが膨らんでいく様子で「もうすぐはじけるよ」と赤ちゃんに促しやすくしたい。

## 3. 受け入れ条件

- 発生直後のバルーンは、これまでと同様の初期サイズで表示される。
- カウントダウンの経過（残り時間の減少）に伴い、バルーンの表示直径が単調に増加する。
- 拡大は滑らかで、激しい点滅・急激な拡縮にならない（穏やかな演出）。
- 破裂して次のバルーンが出ると、サイズは初期サイズに戻ってから再び拡大する。
- 拡大してもバルーンがプレイ領域から大きくはみ出さない（中心基準で配置され、最大サイズを超えない）。
- `prefers-reduced-motion` 有効時は拡大アニメーションを低減する（既存方針を踏襲）。
- タップ判定・数字表示・色・スコアなど既存機能の挙動は変わらない。
- `npm run lint` / `npx tsc --noEmit` がエラー・警告なしで通る。

## 4. 制約事項

- 拡大は**時刻ベースの進捗**から算出する（`expireAt` と生成時カウントを利用）。`setInterval` の回数カウントに依存しない。
- 状態はセッション内のみ・非永続（localStorage/Context を使わない）を維持する。
- 拡大の上限倍率・初期サイズは `@/lib/constants` に定義し、マジックナンバーを散らさない。
- はみ出し防止：位置の余白（`POSITION_MARGIN_PCT`）と最大サイズの整合を保つ。
- Git 操作は行わない。
