# 要求内容 — バルーン遊び機能（P3）

## 0. この作業バッチの位置づけ

- 作業バッチ名：`20260915-balloon-game`
- 対象：バルーン遊び画面（`/play`）の実装。開始・停止・スコア表示・バルーン生成/カウントダウン/破裂。
- 依存：**`20260915-foundation` 完了が前提**（ナビ・共通UI・`constants` の `BALLOON_COLORS`/`COUNTDOWN_MIN/MAX`・`id` を利用）。
- 並行性：foundation 完了後は life-log / schedule と**完全に独立して並行開発可能**。本機能は logs/schedules 状態を使わず、`useBalloonGame` は Context を購読しない画面ローカル・非永続の状態。

## 1. 変更・追加する機能の説明

バルーン遊び画面（`/play`）を構築する。`docs/functional-design.md` 4.3・`docs/glossary.md` 3章 準拠。

- 「開始」でランダム位置に大きめのバルーンを1つ生成。色はパレットからランダム。
- バルーン内の数字が約1秒ごとにカウントダウン（初期値 3〜5 ランダム）。
- 0 で自動破裂（スコア加算なし）→ 次のバルーン生成。
- 0 前にタップで破裂 → スコア+1 → 次のバルーン生成。
- スコアを常時表示。
- 「停止（Stop）」で終了し「おめでとう {score}個 おせたね」を表示。
- 停止後「もう一度」で score=0 に戻して再開。

## 2. ユーザーストーリー

- 保護者として、ぐずる赤ちゃんに見せる簡単な遊びを起動したい（あやすため）。
- 赤ちゃんとして、画面をタップするとバルーンがはじけて楽しい反応がほしい。
- 赤ちゃんとして、数字がカウントダウンして0で破裂するのを楽しみたい。
- 保護者として、停止したときに「何個押せたか」を見て一緒に喜びたい。

## 3. 受け入れ条件

- 開始でランダム位置にバルーンが出現し、発生時は見やすい大きめサイズからスタートする。
- バルーン内に数字が表示され、その数からカウントダウンする（初期値 3〜5 ランダム）。
- 0 になると自動破裂し、次のバルーンが出る（このときスコアは増えない）。
- 0 前にタップするとはじけ、スコアが1増えて次のバルーンが出る。
- 出現ごとにバルーンの色がパレットからランダムに変わる。
- スコアを画面上に常時表示する。
- 停止すると押下個数と「おめでとう {score}個 おせたね」を表示する。
- 停止後に再開でき、スコアは0にリセットされる。
- カウントダウン到達とタップがほぼ同時でも、二重に次のバルーンを生成しない（競合防止）。
- プレイ中に他画面へ遷移するとゲームは終了する（スコア非保持）。
- `npm run lint` / `npx tsc --noEmit` がエラー・警告なしで通る。

## 4. 制約事項

- 状態はセッション内のみ・非永続（localStorage/Context を使わない）。
- カウントダウンは**時刻ベース**（`expireAt`、`残り=ceil((expireAt-now)/1000)`）で実装し、タイマードリフト・非アクティブタブのスロットリングの影響を抑える。
- タイマー/最新スコアは `useRef` で保持し stale closure を避ける。タイマー・リスナは状態遷移/アンマウントで必ず解除。
- 破裂処理は「現在表示中バルーンID一致時のみ」実行（二重生成防止）。
- 色パレット・カウント範囲は `@/lib/constants`（`BALLOON_COLORS` / `COUNTDOWN_MIN` / `COUNTDOWN_MAX`）を使う。ID は `@/lib/id`。
- アクセシビリティ：激しい点滅を避け穏やかなアニメーション、`prefers-reduced-motion` で低減、各背景色で数字が読めるコントラスト、スコア/結果は `aria-live` で通知。
- ページ（`app/play/page.tsx`）は薄く保ち、UI 実体は `components/balloon/` に置く（機能識別子は `balloon`）。
- Git 操作は行わない。
