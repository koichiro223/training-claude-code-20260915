# 要求内容 — 生活ログ記録機能（P1）

## 0. この作業バッチの位置づけ

- 作業バッチ名：`20260915-life-log`
- 対象：生活ログ画面（`/logs`）の実装。記録の追加・一覧・編集・削除・クイック記録。
- 依存：**`20260915-foundation` 完了が前提**（型・`useLogEntries`・共通UI・ナビ・datetime/constants を利用）。
- 並行性：foundation 完了後は schedule / balloon-game バッチと**独立して並行開発可能**（共有するのは Context 経由の `logs` 状態のみで、実装ファイルは重複しない）。

## 1. 変更・追加する機能の説明

生活ログ画面（`/logs`）を構築する。`docs/functional-design.md` 3.3・4.1 準拠。

- **クイック記録**：よく使う種別（授乳・ミルク・おむつ等）ボタンで現在時刻即記録（PRD「3タップ以内」担保）。
- **記録追加フォーム**：種別／日時（既定=現在時刻）／メモ。`temperature` は数値入力欄を表示。
- **一覧**：`occurredAt` 降順、ローカル暦日でグルーピング。
- **編集・削除**：各項目を編集・削除（削除は確認モーダル）。
- **空状態**：0件時に追加を促す。

## 2. ユーザーストーリー

- 保護者として、授乳した時刻をすぐ記録したい（授乳間隔把握）。
- 保護者として、記録を一覧で見返したい（1日の流れの振り返り）。
- 保護者として、間違えた記録を修正・削除したい（正しい記録の維持）。

## 3. 受け入れ条件

- 種別と時刻を指定して記録を追加でき、一覧に反映される。
- クイック記録ボタンで現在時刻の記録がワンタップ〜数タップで追加できる。
- `temperature` 選択時は数値入力欄が出て、数値が必須・妥当範囲（30〜45℃）でバリデーションされる。
- 一覧は新しいものが上（`occurredAt` 降順）で、日付ごとの見出しでグルーピングされる。
- 記録の編集・削除ができる。削除は確認モーダルを挟む。
- 端末を再度開いても記録が残っている（永続化は Context/foundation が担保）。
- 0件時に空状態メッセージを表示する。
- `npm run lint` / `npx tsc --noEmit` がエラー・警告なしで通る。

## 4. 制約事項

- 状態・永続化は `useLogEntries()` 経由のみ。localStorage を直接触らない。
- 型は `@/types`、日時変換は `@/lib/datetime`、定数は `@/lib/constants`、確認モーダル・通知・空状態は `@/components/ui` を使う（自作しない）。
- バリデーション：日時必須・パース可能（未来日時許容）、体温は数値必須・30〜45℃、メモ最大500文字。
- ページ（`app/logs/page.tsx`）は薄く保ち、UI 実体は `components/logs/` に置く。
- XSS 対策（React 標準エスケープ、`dangerouslySetInnerHTML` 不使用）。
- Git 操作は行わない。
